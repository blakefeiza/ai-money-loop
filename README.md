# The AI money loop

A scroll-through, plain-English guide to the circular deals behind the AI boom. Static site, no build step: `index.html`, `style.css`, `app.js`, `data.js`, plus `logos/`.

- All companies, arrows (with status and source), story steps and "why" carets live in `data.js`.
- Arrow direction = where the money goes. Arrow thickness = dollars, where known. Status per arrow: announced, reported or disputed.
- Figures come from press reports and filings, 2025 to mid-2026, and some conflict. Contract values are promises, not cash.
- Company logos are trademarks of their owners, used to identify them.
- Preview locally: `python3 -m http.server 4330`.
- Embed in Tableau with a Web Page object pointing at the GitHub Pages URL.

By Blake Feiza, Feiza Data.
